# 灵动岛新增功能测试说明

本文档面向测试同学，说明本次灵动岛围绕**「动态感知工具与账号变化」**新增的功能范围，以及每一项功能的实操测试方法与通过标准。

---

## 一、本次新增功能概览

| 序号 | 新增功能 | 一句话说明 |
| :--- | :--- | :--- |
| 1 | **自动跟随正在运行的工具** | 哪个命令行工具开始干活，灵动岛就自动切过去显示它的实时 Token；多个工具同时跑时不会乱跳，点胶囊右侧的并发工具图标可手动轮换，多会话并发圆圈也完整保留。 |
| 2 | **关闭终端窗口秒级停表** | 在 Kimi、OpenCode、Qwen Code、Pi 等工具聊完直接退出或关掉窗口后，2 秒内灵动岛自动结束忙碌态，不再空挂 90 秒。 |
| 3 | **外部切号自动跟随与直连记账** | 用 CC Switch 等外部工具切换到已在 Jolu 录入过的 Key / 账号时，灵动岛半秒内自动跟过去，直连聊天的花费也会记到该账号名下。 |
| 4 | **未收录凭证提醒与一键收录** | 检测到本机正在使用 Jolu 没保存过的 Key 或新账号时，自动收起旧额度防止看错，展开灵动岛点一下即可直接收入「供应商」管理（胶囊与经典两种样式均支持）。 |
| 5 | **本地官方登录换号自动刷额度** | ZCode、Gemini CLI、OpenCode、Grok CLI 在本地切换官方登录账号后，无需手动点刷新，灵动岛自动清掉旧缓存并刷出新账号额度。 |
| 6 | **Agent 接线被改走实时提示** | 已接入 Jolu 模型路由的工具，如果在外部被其他软件改掉了配置，不用点重新检测，半秒内自动提示「配置被改动」。 |
| 7 | **Qwen Code 本地会话采集** | 不走网关、直接用 Qwen Code 聊天时，灵动岛、用量统计和会话线程也能实时看到它的对话标题、项目目录与 Token 用量。 |
| 8 | **后台等待确认置顶提醒（可选）** | 开启开关后，后台终端里的 Claude Code / Codex 等你按确认（如权限审批）时，灵动岛会亮起橙色提醒；关闭开关后自动还原配置不留残留。 |

---

## 二、测试前准备（约 1 分钟）

1. 启动桌面端应用，确保桌面上能看到浮动**灵动岛**。
2. 打开 Jolu 主窗口 → 点击左侧导航 **「灵动岛」** → 找到 **「联动与判定」** 卡片：
   - 确认 **「智能跟随活跃 Agent 与账号」** 开关为 **开启**（默认已开启）。
3. **测试小提示**：
   - 如果同时开着「跟随主窗口」，主窗口正在查看某个账号时会临时优先显示该账号。测下面第 1～5 项时，建议**先把主窗口最小化**（或停留在「灵动岛」设置页），观察最直观。

---

## 三、功能测试点与操作步骤

### 测试点 1：单个与多个工具运行时的自动跟随与气泡切换

- **前置条件**：电脑已安装至少两个命令行工具（如 Claude Code、Codex、Kimi、OpenCode、Qwen Code 任选其二）。
- **测试步骤**：
  1. 先让灵动岛停在工具 A（例如 Claude）；打开一个终端运行工具 B（例如 Codex），输入一个需要思考十几秒的问题；
  2. 趁工具 B 还在输出内容，再打开第二个终端运行工具 A（Claude），同样发一个问题；
  3. 点击胶囊灵动岛右侧的**并发工具图标徽章**（若当前工具本身开了 2 个及以上并发会话，胶囊外侧的旋转计数圆圈也会同时保留显示）；
  4. 让当前工具执行一条**耗时超过 2 分钟的长命令**（如编译、跑全量测试或 `Start-Sleep -Seconds 130`）；
  5. 等待当前显示的工具真正回答完毕，观察 2～3 秒后的变化。
- **预期结果**：
  - 步骤 1：问题刚发出（无需等十几秒首包返回），灵动岛**立即切到工具 B** 并进入忙碌态，有输出后滚动显示实时 Token；
  - 步骤 2：工具 A 同时开跑时，灵动岛主画面**稳稳停在工具 B 不来回闪跳**，胶囊右侧出现带绿色呼吸点的后台工具图标栈；
  - 步骤 3：点击右侧并发工具图标后，主画面立刻切换到另一个正在运行的工具，且不会覆盖外侧的多会话并发旋转圆圈；
  - 步骤 4：长耗时命令静默执行超过 90 秒～数分钟期间，灵动岛**持续保持运行态，不会中途误判为已结束**；
  - 步骤 5：当前工具整轮回答真正结束后约 2.4 秒，自动平滑接力切向仍在运行的另一个工具（若无其他工具运行则平稳结束）。

---

### 测试点 2：关闭终端窗口后灵动岛快速收尾

- **前置条件**：电脑已安装 Kimi、OpenCode、Qwen Code、Pi、DSH 或 Gemini CLI 中的任意一个。
- **测试步骤**：
  1. 打开终端启动上述任一工具，随便问一句简短问题；
  2. 等它刚回答完（此时灵动岛显示该工具活跃），直接在终端输入 `exit` 退出，或**直接点击终端窗口右上角 `×` 关掉窗口**，开始读秒。
- **预期结果**：
  - 关掉窗口后 **2～3 秒内**，灵动岛结束该工具的活跃/写入状态（若无其他工具运行则回到空闲态），不会再拖着一分半钟不灭。

---

### 测试点 3：在外部切换到「已录入账号 / Key」时的自动跟随与记账

- **前置条件**：Jolu「供应商」页面里已保存至少 2 个可用账号或 API Key（包含第三方中转站自定义供应商 Key 亦可）。
- **测试步骤**：
  1. 使用 CC Switch（或直接编辑对应工具的配置文件，如 Claude、Codex、Kimi、OpenCode），把本机正在用的 Key 切换到 Jolu 里已保存的**另一个连接**；
  2. 不接入模型路由（保持工具直连），在该工具里发一句话产生一次调用；
  3. 打开主窗口 **「用量统计」** 页面，按刚才切换过去的那个连接筛选今日记录。
- **预期结果**：
  - 步骤 1：外部保存配置后 **约半秒内**，灵动岛弹出轻提示 **`已跟随 · <连接名称>`**，自动切到对应连接；
  - 步骤 2 & 3：灵动岛连接名称旁显示 **`本机`** 小标签，且「用量统计」中能查到刚才那笔直连调用已归入该连接名下。

---

### 测试点 4：未收录 Key 提醒与灵动岛「原地一键收录」（双样式）

- **前置条件**：准备一把**尚未添加到 Jolu「供应商」页**的有效 API Key 与接口地址。
- **测试步骤**：
  1. 在任一支持工具（如 Claude Code、Codex、OpenCode、Kimi、Pi、Qwen Code）的本机配置文件里填入这把未保存的 Key 并保存；
  2. 观察灵动岛收缩态的提示，然后**双击灵动岛展开卡片**；
  3. 点击卡片里的 **「一键收录到账号管理」** 按钮；
  4. 打开主窗口「灵动岛」页，将样式切为 **「经典」**，换另一把未收录 Key（或删掉刚建的连接）再看一次经典样式下的表现。
- **预期结果**：
  - 步骤 1：半秒内灵动岛自动收起旧账号的额度环（防止把旧账号额度误当成新 Key 的额度），显示橙色 **`未收录 sk-****xxxx`**；
  - 步骤 3：点击「一键收录到账号管理」后，无需打开主窗口手动填表，橙色警告消失，直接切换为新建好的 **`<工具名> · <网关域名>`** 正式连接；打开主窗口「供应商」页能看到该连接已在列表中（若网关支持拉取模型，模型清单也已自动同步）；
  - 步骤 4：**胶囊样式**与**经典样式**在收缩态与展开态下均能正常提示并完成一键收录。

---

### 测试点 5：本地官方扫码 / 网页登录换号自动刷新额度

- **前置条件**：使用 ZCode、Gemini CLI（Google 登录）、OpenCode（OpenAI 登录）或 Grok CLI 中的任意一款，且已在 Jolu 关联其本机登录。
- **测试步骤**：
  1. 先看一眼灵动岛当前显示的账号剩余额度；
  2. 在原工具客户端或命令行里退出当前账号，登录**另一个官方账号**（全程不要点灵动岛右键刷新）。
- **预期结果**：
  - 登录完成后半秒内，Jolu 自动清理上一个账号的旧额度缓存并重新拉取，灵动岛上的额度数字更新为新账号的真实额度。
  - *(补充：如果此前还没在 Jolu 关联过该平台的本机登录，登录完展开灵动岛同样可以点「一键收录到账号管理」直接关联。)*

---

### 测试点 6：Agent 接线被外部软件改走时的实时变色提醒

- **前置条件**：主窗口 **「Agent」** 页面中至少有一个工具处于 **「已接入 · 配置一致」** 状态。
- **测试步骤**：
  1. 把 Jolu 主窗口停在 **「Agent」** 列表页，鼠标不要点任何刷新按钮；
  2. 用 CC Switch 或记事本打开该工具的配置文件，把里面的网关地址改成别的地址（或删掉）并保存。
- **预期结果**：
  - 保存文件后 **1 秒内**，主窗口「Agent」页里该工具卡片以及胶囊灵动岛上的工具小图标自动变色，状态即时更新为 **`配置被改动，未经路由`**。

---

### 测试点 7：Qwen Code 直连会话与 Token 用量采集

- **前置条件**：本机已安装 Qwen Code（`qwen`），且处于未接入 Jolu 网关的**直连状态**。
- **测试步骤**：
  1. 打开终端运行 `qwen`，发送一句容易辨认的问题（例如：「用一句话介绍你自己」）；
  2. 等回答完成后，打开 Jolu 主窗口查看 **「会话线程」** 与 **「用量统计」**（筛选 `Qwen Code`）。
- **预期结果**：
  - 对话时灵动岛能切换到 **Qwen Code** 图标并显示今日/本轮 Token；
  - 「会话线程」中能看到刚才那条会话的提问标题与所在项目文件夹，「用量统计」中能看到对应的 Token 消耗记录。

---

### 测试点 8：后台等待权限确认提醒与开关无痕还原

- **前置条件**：电脑已安装 Claude Code 或 Codex。
- **测试步骤**：
  1. 打开主窗口 **「灵动岛」→「联动与判定」**，开启 **「后台等待确认提醒（Claude Hooks / Codex Notify）」**；
  2. **新开一个终端窗口**启动 `claude`，让它执行一个需要用户审批确认的操作（例如运行一条未授权命令），当终端停在询问确认界面时，不要按键，切到桌面看灵动岛；
  3. 点击灵动岛上的橙色提醒文字；
  4. 测完后回到「灵动岛」设置页，将 **「后台等待确认提醒」** 开关**关闭**，打开 `~/.claude/settings.json`（或 `~/.codex/config.toml`）检查文件内容。
- **预期结果**：
  - 步骤 2：终端停下等待确认时，灵动岛亮起橙色提醒（如 **`等待授权确认`**）；
  - 步骤 3：点击提醒可唤起主窗口定位到会话；
  - 步骤 4：关闭开关后，配置文件中由 Jolu 添加的 `--agent-hook` 配置已被干净移除，用户自己原有的配置保持原样。
